# Evaluation for StixelNExT && StixelNExT++

## Evaluation
The `evaluate.py` script is to apply the metric to StixelNExT++ results, based on Waymo-OD `.tfrecord` files. The 3D 
bounding boxes will be used to evaluate recall and precision of predicted Stixel.

## Analyse
The `evaluate.py` script is to check multiple thresholds for a model and give an overview like expected outputs or some
results. 

## Explore
The `utils/explore_data.py` script is to check qualitative results of Stixel predictions.
